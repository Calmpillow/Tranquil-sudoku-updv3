TRANQUIL SUDOKU — SIMPLE GITHUB PAGES VERSION

No Firebase, Supabase, email login, API keys, SQL, npm, or build tools are required.

UPLOAD:
1. Extract this ZIP on your phone.
2. Upload ALL four files (index.html, manifest.webmanifest, sw.js, icon.svg) to the ROOT of your GitHub repository.
3. If GitHub asks, replace the old files.
4. In GitHub repository Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
5. Open the Pages URL after deployment.

PLAYER SAVES:
Each player enters a username. Their progress is saved automatically in that browser on that device. Different usernames have separate saves. Friends using their own phones get their own fresh saves.

IMPORTANT LIMITATION:
These are local browser saves, not cloud accounts. A player's progress does not follow them to another device or another browser. Clearing browser data can erase local saves. No email or account setup is needed.

Animated backgrounds: falling sakura petals, drifting leaves, gentle water ripples, twinkling dusk stars, and floating golden garden blossoms. Motion is subtle and respects reduced-motion settings.
